אני רוצה להוסיף למערכת מסך הגדרות חדש לניהול טמפלט PDF של הצעות מחיר.

חשוב:
- כל הממשק בעברית.
- RTL מלא.
- להשתמש בעיצוב ובקומפוננטות הקיימים בפרויקט.
- לא ליצור עדיין PDF אמיתי.
- לא לאפשר עריכת HTML או CSS חופשי.
- לעבוד מול טבלת Supabase הקיימת:
  public.pdf_templates

## מטרת המסך

לאפשר למשתמש לערוך את התוכן והגדרות התצוגה של טמפלט הצעת המחיר, לראות תצוגה מקדימה חיה, ולפרסם גרסה חדשה של הטמפלט.

## נתיב

הוסף מסך חדש תחת הגדרות:

/settings/quote-pdf-template

שם בתפריט:

טמפלט הצעת מחיר

## טעינת הטמפלט

בעת פתיחת המסך, טען את הרשומה הפעילה מתוך:

public.pdf_templates

לפי:

document_type = 'quote'
status = 'active'
is_default = true

הצג:
- שם הטמפלט
- מספר גרסה
- סטטוס
- תאריך הפעלה

## שמירה

כפתור:

שמור ופרסם גרסה חדשה

אין לעדכן את הרשומה הפעילה הקיימת.

בעת שמירה:
1. טען את הטמפלט הפעיל הנוכחי.
2. העבר אותו ל:
   status = 'archived'
   is_default = false
3. צור רשומה חדשה עם:
   אותו template_key
   version = הגרסה הגבוהה ביותר + 1
   status = 'active'
   is_default = true
   אותו template_path
   name לפי הטופס
   configuration לפי הטופס
   activated_at = now()
   created_by = auth.uid()

חשוב:
- לבצע את השמירה בצורה בטוחה.
- לא להשאיר מצב שבו אין טמפלט פעיל.
- לא להשאיר שתי גרסאות פעילות.
- למנוע לחיצה כפולה.
- להציג הודעת הצלחה או שגיאה.
- לאחר הצלחה לטעון מחדש את הגרסה החדשה.

## דרישות טכניות

- TypeScript מלא.
- אין להשתמש ב-any.
- להשתמש ב-Supabase client הקיים בפרויקט.
- ליצור type בשם PdfTemplateConfiguration.
- לבצע merge עם ברירות מחדל במקרה שחסרים שדות ב-configuration.
- לא לחשוף service role key.
- לא לשנות סכימת DB כרגע.
- לא ליצור PDF אמיתי בשלב הזה.
- לא ליצור מערכת עריכת HTML/CSS.

## Acceptance Criteria

- קיים מסך חדש בהגדרות.
- הכל בעברית RTL.
- נטענת התבנית הפעילה.
- ניתן לערוך שדות ומתגים.
- ה-preview מתעדכן בזמן אמת.
- שמירה יוצרת גרסה חדשה.
- הגרסה הקודמת עוברת ל-archived.
- קיימת רק גרסה אחת active/default.
- היסטוריית גרסאות מוצגת.
