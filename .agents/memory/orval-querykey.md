---
name: orval useGetX hooks require queryKey in options
description: When passing query options to orval-generated useGetX hooks, queryKey is required in the query sub-object.
---

## Rule
```ts
const { data } = useGetProduct(id, {
  query: {
    enabled: someCondition,
    queryKey: getGetProductQueryKey(id),  // required!
  },
});
```

**Why:** The generated `query` option type is `UseQueryOptions<...>` which in React Query v5 requires `queryKey`. Omitting it causes TS2741.

**How to apply:** Always import and use the corresponding `getGetXQueryKey(id)` helper alongside `useGetX`. The helper is auto-generated by orval alongside the hook.
